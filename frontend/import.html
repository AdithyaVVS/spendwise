Import from CSV

Upload a bank statement or spreadsheet export. The file needs a header row, for example:

date,amount,description,category
2026-10-05,250.50,Lunch,Food
05/10/2026,"1,250.00",Metro card,Transport
  • date, amount and category are required, description is optional, and the columns can be in any order.
  • Dates can be 2026-10-05 or 05/10/2026 (day first).
  • Maximum 1 MB and 1000 rows per file.
  • New categories are created for you. Rows you already have (same date, amount, description and category) are skipped, so importing the same file twice is safe.
  • Bad rows are rejected one by one. The good rows are still imported.
